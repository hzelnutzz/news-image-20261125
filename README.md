A deterministic 1024×1024 broadsheet front page of 25 Nov 2026 world news
(US tariffs, Russia–Ukraine, Gaza, Huawei verdict, Colombia siege, China–Pakistan
spaceflight, asteroid-defence test), drawn by `scripts/make.py` and shipped as
`entry.png`. `main.ts` copies it to the output directory.

## Run

```
node main.ts            # copies entry.png to $MAKEFUN_OUTPUT_DIR (default /output)
python3 scripts/make.py # regenerates entry.png deterministically
```
